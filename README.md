# Portfolio - Kellas Andrei

A personal developer portfolio website showcasing experience, technical approach, tech stack, featured projects, services, and certifications. Built with React, TypeScript, and Tailwind CSS.

## Features

- Responsive portfolio layout with desktop sidebar navigation
- Toggleable dark and light theme modes with local storage persistence
- Staggered entrance and scroll-triggered animations using IntersectionObserver
- Comprehensive sections covering experience, tech stack, projects, services, and verified certifications
- Direct contact links and social media integration

## Tech Stack

- Frontend: React 19, TypeScript, Vite
- Styling: Tailwind CSS
- Icons: Phosphor Icons, Lucide React, React Icons

## Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm

### Installation

1. Install dependencies:

```bash
npm install
```

### Development

Run the local development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.

### Build

Create an optimized production build:

```bash
npm run build
```

### Type Checking

Run TypeScript type check:

```bash
npm run lint
```
